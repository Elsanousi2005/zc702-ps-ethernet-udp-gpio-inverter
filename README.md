# ZC702 PS Ethernet UDP GPIO Inverter

This repo contains the UDP inverter application and host-side test script used for the ZC702 Ethernet bring-up. The Processing System (PS) runs a bare-metal lwIP UDP server on GEM0. lwIP is a lightweight TCP/IP stack for embedded systems that provides UDP/IP networking services without an OS. The Programmable Logic (PL) implements a simple datapath: AXI GPIO OUT (32-bit) -> bitwise NOT -> AXI GPIO IN (32-bit). The server receives a 4-byte little-endian word, writes it to the GPIO OUT register, reads back the inverted value from GPIO IN, and replies with 8 bytes: the original word followed by the readback word.

Note: lwIP and BSP sources are generated by Vitis when you create the platform and application. They are not stored in this repo.

## Repository layout
- `vitis/src/` contains the UDP inverter application sources:
  - `app.c`, `udp_inverter.c`, `udp_inverter.h`, `gpio_inverter.c`, `gpio_inverter.h`, `platform.c`, `platform.h`, `platform_config.h`
- `host/host_udp_inverter.py` is the Python test client.
- `vivado/` is reserved for Vivado hardware artifacts for this project (if you choose to store them here).

## UDP protocol
- UDP port: 5005
- Request payload: 4 bytes, little-endian unsigned 32-bit word `W`
- Response payload: 8 bytes, concatenation of `W` then `R` (readback)
- Expected relationship: `R == ~W`
- Length check: if request length is not exactly 4 bytes, the service replies with ASCII `BADLEN`

## DHCP vs static IP (user choice)
This project supports both DHCP and static IP. The behavior is controlled by the platform BSP setting `LWIP_DHCP` generated from the Vitis lwIP settings.

If you want static IP (direct PC <-> board connection, no router), disable DHCP in the platform configuration:
- `lwip220_dhcp = false`
- `lwip220_dhcp_debug = false`
- `lwip220_dhcp_options = false`
- `lwip220_lwip_dhcp_does_acd_check = false`

With DHCP disabled, the application uses the static configuration defined in code (192.168.1.10/24, gateway 192.168.1.1).

If you are connected to a router and want DHCP, enable the settings above. The board will receive a dynamic IP each run. Read the assigned IP from the UART log.

## Build and run (Vitis)
1. Import your hardware XSA into Vitis and create a platform.
2. Ensure the lwIP library is enabled in the platform domain.
3. Create an application and add the sources from `vitis/src/`.
4. Build the application to produce the ELF.
5. Program the FPGA with the matching bitstream and run the ELF on `ps7_cortexa9_0`.
6. Open UART at 115200 8N1 and confirm the service banner and "listening on UDP port 5005".

## Host tests
Make sure the host NIC is on the same subnet as the board when using static IP.

Python test:
```bash
python3 host/host_udp_inverter.py 192.168.1.10 0x12345678
```

Netcat + hexdump test:
```bash
echo -n -e '\x78\x56\x34\x12' | nc -u -w 3 192.168.1.10 5005 | hexdump -v -e '1/1 \"%02x \"'; echo
```
Expected output (for 0x12345678):
```
78 56 34 12 87 a9 cb ed
```

## Troubleshooting
- `BADLEN` response means your UDP payload was not exactly 4 bytes.
- No reply usually means IP mismatch or link issues. Confirm the host NIC IP, netmask, and that the board is reachable with `ping`.
- If the board prints a different IP than expected, verify your DHCP settings and UART log.
